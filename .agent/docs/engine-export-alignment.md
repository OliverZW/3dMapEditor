## 已落实的实现

- 运行导出切换 map3d-engine-export/exportVersion=2，唯一入口、单份权威数组、完整文件清单及报告。
- 地形、PNG16、权重、河流和参考水面；原始模型、独立贴图、参考材质参数；实例与资源索引分开。
- 据点、势力及逐格归属；视觉与逻辑开关独立，草生成依赖独立于视觉开关。
- 标准 GLB 直接写入保留数组顺序，据点只增加水平锚点节点；不改原素材、地图或工程格式。
- 包级校验、字段契约、独立 Node.js 读取示例和用户说明；删除旧场景生成扩展和运行组件。

## 数据验收

- 不对称矩形地形、513²／1025²采样、边界与三角面插值，PNG16 量化误差及唯一连续网格。
- 非零默认缩放／朝向／偏移和实例变换只合成一次，原始 GLB 与独立贴图可读取。
- 城池／要塞、有势力／未分配、中心保护、飞地、逐格归属和派生初始势力。
- 草单独导出、逻辑单独导出、空内容、水面逐顶点数组和无网格水面。
- 模型哈希损坏、文件丢失、路径冲突、重复 JSON 键、NaN、维度／权重／高度不符、失效资源／势力／owner 等失败保护。
- 导出期间快照独立，当前地图和历史不被导出或失败修改。

自动化命令：`node node_modules/vitest/vitest.mjs run tests/engine-export.test.mjs tests/engine-export-contract.test.mjs`；浏览器使用 `test:browser`、`test:builtin-resources` 的工程部分和 `test:map-resize` 中的导出检查，执行情况以实施记录为准。
