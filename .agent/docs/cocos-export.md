# Cocos Creator 3.8 · 地图数据 v2 接入说明

日期：2026-10-25 · 状态：**v2 数据包与独立读取示例已实现；真实 Cocos 导入和运行未验收。**  
关联：[资料索引](README.md) · [通用协议](engine-export-spec.md) · [验收清单](engine-export-alignment.md) · [随包接入说明](../../engine-adapters/cocos/README.md)

## 职责

编辑器只按协议导出地图数据和可替换参考资源。游戏负责文件加载、配置、Prefab／节点组织、贴图／材质替换、草生成和模型批渲染。通用包不包含 UUID 或游戏项目路径；不创建场景、地图 Prefab、资源覆盖系统或双向同步工具。

旧 v1 场景导入扩展和 ShanheMapRuntime 组件已删除，不再随包发送。新入口为 manifest.json 中的 entries 与 files；不再使用 assets/map-data.json、重复 owner JSON 或 assets/ 与包根双路径。

## 接入顺序

1. 从编辑器生成并解压 v2 ZIP，阅读 README、字段契约及通用协议。
2. 以独立 Node.js 示例检查地形采样、实例、据点和初始势力，先验证数据而不是先生成节点。
3. 游戏自行导入标准 GLB 和独立 PNG／WebP／JPEG，按 assetId 建立自己的资源表。引擎资产数据库如何生成资源及子资产，由游戏项目处理。
4. 视觉实例位置、朝向、缩放已经合成，只使用 T*Ry*S；不重复翻转 Z、居中或叠加模型默认缩放。
5. 逻辑格心、辖区和初始势力来自 logic；显示模型的微调、游戏初始配置、运行时归属等由游戏自行管理，不回写编辑器。
6. 游戏将样例中的 Node fs 读取换成适合 Cocos Editor／构建运行时的平台加载；示例不属于 Cocos 运行组件，也没有验证资源桥接或引擎构建。

## 素材及效果

地形 GLB 为单个连续参考网格，附 PNG16、最终高度和地表权重。模型保留原始标准材质和内嵌贴图，另提供独立贴图与可读材质描述。地表、水面和草参数是参考数据，不强制游戏复刻 Three.js shader；可完全采用游戏自有模型、材质及贴图。用户自有或研究素材的使用范围仍按原来源记录执行，不扩大分发授权。

## 验证状态

package 检查与 import／engine 检查独立。当前仅在包、独立读取和浏览器流程层面验证；不填写真实 Creator 补丁号、导入成功、画质一致或游戏性能通过。重新导出、游戏资源版本管理和游戏中的进一步编辑，由游戏项目决定。地图工程仍为 .map3d v3，旧包需从工程重新导出 v2。
