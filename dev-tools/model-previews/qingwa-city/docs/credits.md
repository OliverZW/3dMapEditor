# 资源与许可

- 城池几何：本工程通过 `blender/build_city.py` 自制，无外部模型。
- 材质贴图：本工程通过 `blender/generate_textures.py` 自制，无外部图片贴图。
- 山地阔叶树：树干、枝系、根系与 7,205 片立体叶片通过 `blender/build_tree.py` 自制；树皮颜色、粗糙度和法线贴图通过 `blender/generate_tree_textures.py` 自制，无外部模型或图片。
- 山地松、翠柏、红枫、垂柳：四种独立枝干、树冠与立体叶片通过 `blender/build_tree_variants.py` 自制，复用本工程自制树皮贴图；固定随机种子可重复生成，无外部模型或图片。
- 建筑形制参考：用户提供的《三国志14 威力加强版》城池截图，以及中国大百科全书“瓮城”、中新网“平遥古城”、商洛学院“中国古建筑屋顶图解”；仅作特征研究。
- Edit3D 预览环境：随 editor 插件提供的 sky、terrain、grass、rocks 与 tonemap 模块。
- 未使用《三国志14》或其他游戏的提取模型、贴图和音频；参考截图不进入 GLB。
