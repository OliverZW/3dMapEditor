# 第二轮渲染性能优化与验收

日期：2026-10-25。归属：所有地图共用的编辑器开发，不制作地图作品。

## 范围与默认路径

用户批准保持当前画质：不改变地图对象、原始 GLB／PNG、LOD 阈值、分辨率、抗锯齿、阴影、地表过滤、工程格式或 Cocos 导出。

默认启用以下两项：

- 模型视锥与 LOD 仍随相机更新；逐层比较不可变实例记录及槽位顺序，未变化时跳过矩阵计算和上传。增删、变换或层级变化通过重建或对应槽位更新处理，稳定 ID 和独立阴影批次保留。`uploadBytes` 统计安排提交的实例矩阵字节，不是显存占用量。
- 连续单片地形复用位置和法线缓冲，累计 `RenderInvalidation.bounds`，更新脏区顶点及扩展一圈的法线。上传范围保留至实际上传后清空，首次 `bufferData` 也清除范围，避免下一次雕刻携带首帧整图范围。尺寸、采样、工程切换、回滚和未知范围使用全量更新；包围体使用文档高度上下限构造保守范围。

最终高度派生、河床计算、植被过滤／贴地、逻辑覆盖仍沿用原算法，本轮没有消除它们的全量计算。这里的局部更新收益只针对显示网格。

## 候选评估与关闭原因

地表共享投射梯度已实现开发对照，导数在任何贡献与距离分支前求值，保留显式梯度采样。四层混合 513² 场景，1600×1000、DPR 1、HD 630／ANGLE D3D11、MSAA、2048 阴影与各向异性过滤 4；每档预热 4 秒，测 10 秒，重复三轮：

- 近景 GPU 中位数 82.115 → 81.753 ms。
- 中景 128.934 → 128.876 ms。
- 远景 90.837 → 91.284 ms。
- 三档画面 P99 均为零、最大通道差异不超过 1／255；性能基本持平，不满足稳定提速条件，默认关闭。完整条件和原始测量见 [共享梯度报告](../../test-results/archive/legacy-2026-11-01-104237/render-optimization-shader.json)。

内置模型合批作为独立派生缓存实现，按资源 ID、源哈希和 LOD 层级共享。松、柏、枫、柳使用线性顶点色；阔叶树保持不同粗糙度分组；几何归派生缓存，原材质与贴图归原模型，新增叶冠材质独占并释放。

城池原拟烘焙不同局部变换后按材质合并，固定画面出现少量屋檐超限像素，未保留为默认实现。当前候选只合并变换与属性兼容的网格，保留原矩阵顺序；新增叶冠材质另保留原材质绘制顺序。同一视口最终复核中，近／远景差异为零，中景仍有一个像素差异 5／255，未满足最大差异≤1／255 的门槛，默认继续原批次，不能以平均误差或 P99 为零替代最大像素门槛。候选无需且不会改写素材清单或派生 LOD 文件。最终候选对照见 [同一视口候选画质报告](../../test-results/archive/legacy-2026-11-01-104237/render-optimization-shader-quality.json)。

分页材质缓存继续关闭；三角形提交顺序实验无稳定收益，不纳入实现。

## 验证方法和产物

- `npm run test:render-optimization`：独占一个测试浏览器、每次一个视口，完整地图／四层地表／简单平面独立模型，513² 和 1025²，近中远视角；每档预热 4 秒、测 10 秒、重复三轮，另测相机运动。记录 GPU 时间、FPS、P95、Draw、实例提交字节和资源数量。基线保留已有 LOD、裁剪和静态阴影，仅关闭第二轮更新优化。
- 固定画面和性能均在同一 WebGL 上下文、同一资源内切换模式；各模式在当前相机刷新完整阴影，避免独立实例的初始化差异污染对照。默认固定画面门槛为 P99=0、最大单通道差异≤1／255。截图时冻结第 7 秒；所有场景都是程序验收夹具。1025² 完整地图由同一示例重采样，保留原网格坐标及全部对象，不是新地图作品。
- `--shader --probe` 只测四层地表共享梯度；`--shader --quality-only --full-probe` 评估完整候选画质；两者均不改变产品默认设置。开发构造选项 `performanceMode: 'baseline' | 'candidate'` 无 UI 入口，不进入文档、历史或保存。
- `npm run test:render-updates`：两种采样规模各连续雕刻 12 次，对照全量重建的位置／法线及拾取高度，验证撤销重做、取消、快速工程替换、关闭回收和原始／派生资源只释放一次。

正式矩阵与截图：[默认路径完整报告](../../test-results/archive/legacy-2026-11-01-104237/render-optimization.json)。编辑与生命周期：[更新专项报告](../../test-results/archive/legacy-2026-11-01-104237/render-update-smoke.json)。此前的模型及地表性能报告保持独立。早期跨实例尝试发现默认路径也有少量像素差异，已停止并保留为 render-optimization-cross-context.json，不作为最终画质验收或收益结论。

## 完整矩阵结果

108 段静止性能采样、12 段相机运动测量完成，浏览器错误为零。18 组默认路径固定画面均为 P99=0、最大通道差异=0。人工查看完整地图近景的城池、树冠、河岸与阴影，以及 1025² 地表近景的材质边界和坡面，未发现新增显示差异。

- 完整地图 513² 中景：GPU 126.133 → 125.913 ms，FPS 7.656 → 7.684，Draw 均为 61；1025² 中景：GPU 251.055 → 251.705 ms，FPS 3.910 → 3.903，Draw 均为 61。静止 GPU 成本基本持平，完整地图仍未达到流畅编辑标准。
- 相同 10 秒小幅平移，完整地图 513² 的安排矩阵提交量 40,805,248 → 2,790,080 字节（减少约 93.2%）；1025² 为 16,210,304 → 2,093,120 字节（约 87.1%）。
- 独立模型场景的提交量：513² 为 114,031,104 → 2,964,160 字节，1025² 为 110,118,272 → 2,964,160 字节（均减少约 97%）。这些运动数据是各一次 10 秒诊断，不作为同幅度 FPS 提升的证据。
- 所有静止采样的模型上传计数为零；相机变化时仍会执行裁剪和层级判断。各观察档首次加载不同 LOD 可增加缓存中的 Geometry 数，不能把它与持续泄漏混为一谈；释放另由更新专项检查。
- 513² 地表近景原始采样存在负载波动，三轮基线与优化相差异常，不能归因为静止渲染算法提速；保留原记录，并单独运行 `--case=surface-513-close` 复测：GPU 中位数 151.956→151.128 ms，FPS 6.005→6.066，逐像素差异为零；[复测报告](../../test-results/archive/legacy-2026-11-01-104237/render-optimization-surface-513-close.json) 独立保存，未覆盖初测。

## 连续雕刻结果

1200×800、DPR 1、256×256 米、半径 4 米、强度 0.15 的抬高画刷，沿固定轨迹连续编辑 12 次：

- 513² 网格更新中位数：23.1 → 0.1 ms；两种属性提交量 6,316,056 → 8,688 字节，顶点更新数 263,169 → 324。
- 1025² 网格更新中位数：92.8 → 0.6 ms；两种属性提交量 25,215,000 → 30,264 字节，顶点更新数 1,050,625 → 1,190。
- 每组最终位置、法线与全量重建一致，拾取高度一致；撤销重做、取消、快速切换采样／矩形尺寸通过。关闭后渲染器几何计数为零；另检查原始／派生几何和材质的释放事件均恰好一次。

这些是显示网格 CPU 更新与安排提交量，不是整帧 GPU 时间、GPU 显存字节或整条编辑流程的加速倍数。完整地图流畅度按完整矩阵报告判断，不宣称达到 30 FPS。

最终源码全量 221 项单元测试、TypeScript、生产构建、源码引用和本轮改动文件格式检查通过；生产主包约 1126 KB，仍有原有大包提示。模型专项 7 组、主浏览器 9 组、交互 8 组及新增更新／释放专项全部通过。
