### 已完成的能力

- 运行导出切换 `map3d-engine-export/exportVersion=2`；以 manifest 的 entries／files 为唯一入口，权威高度、权重、密度和 owner 数组不再在 assets 与包根重复存储。
- 输出单个连续地形 GLB、最终高度、真实 PNG16 及参数、地表权重／贴图、河流和交汇去重水面及其深度／岸距／流向、有效树实例、草参数与排除依赖、据点、初始势力和逐格归属。
- 逻辑资源 ID 与实例变换分开，默认 yaw／scale／offset 只合成一次。模型保持原始几何、材质与纹理；据点仅增加水平居中包装节点。内嵌模型贴图另提取独立 PNG／WebP／JPEG，保留原编码、内容去重，并提供 glTF 材质字段及纹理采样说明 JSON。
- IO 直接编码标准 GLB，不再调用浏览器 GLTFExporter 或渲染模型库；不依赖 DOM 图片重编码。只导出草时保留河流和据点足迹，关闭据点视觉时仍可独立保留逻辑。
- 字段契约与包级检查覆盖路径／预算／哈希、JSON 结构与重复键／BOM、数组维度／值域、图片、PNG16 与高度一致性、GLB 地面坐标、模型引用、中心保护、势力及 owner、水面逐顶点引用；失败不发布 ZIP。
- 使用现有锁定的 Ajv 8.17.1 校验契约，分类从开发依赖调整为应用依赖，未升级依赖版本。API 保留可选 target／mode，默认 Cocos／production；不再以专有 shader 或引擎材质还原作为数据导出门槛。
