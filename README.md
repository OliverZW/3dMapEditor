# 山河 · 三维战略地图编辑器

基于 Three.js、React 和 TypeScript 的桌面浏览器地图编辑器。地面是一个连续规则网格，以浮点高度场保存；六边形是独立的逻辑层。原有 `mapEditor` 工程不参与本工程构建。

## 运行

Windows 双击 **启动编辑器.cmd**，或在 PowerShell 执行 `./start-editor.ps1`。启动器优先使用本机已有的 Codex Node 24 运行时，否则使用系统 Node；服务只监听本机 `127.0.0.1`。浏览器打开 `http://127.0.0.1:5173/`。停止时在启动终端按 Ctrl+C。

其他电脑需要 Node.js 22.12+（推荐当前 LTS），首次执行 `npm ci`，然后 `npm run dev`。已有依赖无须每次重装。源码引用检查使用 npm run check:unused；据点／势力交互专项检查使用 npm run test:interaction，导航／资源面板检查使用 npm run test:navigation-resources（需先启动开发服务）。生产检查使用 `npm test`、`npm run build`；`npm run preview` 预览 `dist`。

首次启动展示可直接修改的示例地图；“新建”可以设置宽长并创建 513² 或 1025² 空白地形。启动器不会自动安装软件或修改系统环境变量。

## 基础操作

- 左侧“概览”查看工程与地面参数，设置宽长后先预览、再确认；每边 1～16384 整数米，中心扩边／裁边，采样数保持不变。缩小会裁除越界对象并截断河流，整个调整可撤销。
- 地形雕刻模式和地表材质选择在左侧编辑面板，半径、强度、衰减等画刷参数留在右侧；其他工具常用操作固定在右侧属性顶部，参数区独立滚动。六边形自动覆盖整片地面，边缘半格裁切。

- 透视按住右键观察＋WASD 移动，QE 升降、Shift 加速，右键期间滚轮调速；正交右键＋WASD 平移。中键或空格+左键平移，滚轮缩放，Alt+左键环绕。
- 右上坐标系点击 X／Y／Z 正轴切换观察方向，中心切换投影，Shift+中心恢复斜向透视。F 定位、Home 全图、V 投影、G 格线；输入框和弹窗不触发地图快捷键。
- 地形、地表、树木和草丛按住左键涂刷；Shift 反转升降或临时擦除植被。一次拖动一次撤销。
- 在左侧“河流编辑”点击“新建河流”，再在地图点击添加控制点，选点拖动，Enter 或“确认”应用；Esc 取消。右侧可改名，已有河流失焦提交，预览名称随确认提交。不同河流允许交叉与接入，确认时交汇连通组统一采用本次编辑水位，可一次撤销；单条河流仍禁止自交。基础高度和河床分别保存。
- 据点与辖区在同一工具中编辑；列表切换据点保留绘制模式和半径。城池与要塞悬停预览、左键点击锁定格心，再确认；所有中心受保护，允许飞地。
- 势力面板支持列表或“地图点选”连续添加城池／要塞，两种方式互斥；再次点击当前入口或 Esc 全部关闭，切换势力或工具清除添加状态。成员支持定位和移出，成员变更均可撤销。据点移动保留辖区原坐标，势力范围由成员派生。
- 图层开关平铺在地图左上角，可分别显示格线、范围、树草和据点；视口左下角显示 FPS／Draw，末尾键盘按钮控制右下操作提示；提示中省去全图／投影／格线重复条目，按键仍有效。
- 树木／草丛左栏虚拟列表选模型，可直接导入或打开单模型详情；右侧工具属性提供刷入／擦除，树木另有选择实例。离开据点工具自动清除据点选择高亮。
- Ctrl+S 下载自包含 `.map3d` 工程；Ctrl+Z / Ctrl+Y 撤销重做。草稿每 30 秒保存到当前浏览器，启动可选择恢复。
- 高度图导出是真 16 位灰度 PNG，附方向参数；它不包含树木、模型或逻辑辖区。
- 资源库支持静态、内嵌资源的 GLB 模型；模型会随工程保存。

## 工程结构与交付状态

编辑器开发与地图制作分别验收：前者交付可复用的软件能力，后者使用现有工具交付具体地图工程。目录、启动示例、测试场景、素材与生成产物的详细说明从 [项目资料索引](.agent/docs/README.md) 的“理解工程与后续系统划分”进入。

`src/core` 为纯数据和算法，`application` 协调编辑与历史，`renderer` 负责 Three.js，`ui` 管理面板，`io` 管理工程、高度图与导出，`platform` 负责浏览器文件和草稿。`engine-adapters/cocos` 保存数据包接入说明和独立读取示例，不创建游戏场景。

引擎导出已实现[通用 v2 数据协议](.agent/docs/engine-export-spec.md)：提供地形、实例、初始归属及标准模型、独立贴图和材质参数，游戏自行读取、配置和替换素材，不自动生成场景。包内附字段契约与独立读取示例；执行 `npm run test:engine-export` 检查包与读取行为。**真实 Cocos 导入与运行尚未验收。** 工程仍为 v3，旧引擎包请从原工程重新导出。

当前工程格式为 v3，支持迁移旧 v1／v2 并提示重新保存；格号可能重新编号，世界位置与归属保留。尺寸专项验证使用 npm run test:map-resize。

后续地图工作目录与专属入口已确定，见[地图工程目录与文件规范](.agent/docs/map-project-format.md)：一工程一地图、`project.map3dproj` 入口，内置素材共享锁定，自定义素材归工程；`.map3d` 目标作为自包含 v4 备份。**这是待实现规范，当前应用仍使用浏览器与 v3 工程包；桌面应用和文件夹读写未交付。**

`editor-assets/` 保存编辑器内置静态资源，由 `vite.config.ts` 配置发布；`engine-adapters/cocos/` 保存游戏侧接入说明及独立读取示例；`dev-tools/` 保存开发检查与资源加工工具。它们分别由原 `public/`、`integrations/cocos/`、`scripts/` 更名，完整职责见[技术设计](.agent/docs/technical-design.md)。

当前地图浮层参考 editor-main.png 恢复深灰绿色半透明背景、低饱和浅灰绿图标文字及淡白蓝选中高亮与柔和光晕，无蓝色按钮底；快捷键恢复细边框小键帽。工具条位于左上，FPS 位于左下，单行提示位于右下，两侧面板布局与既有光照保持不变。界面专项检查使用 `npm run test:ui-refresh`（需先启动开发服务），实际运行截图从项目资料索引查看。

需求、设计、实际验证与当前实现边界统一从 [项目资料索引](.agent/docs/README.md) 阅读。首版是可运行的编辑基础，不代表全部 v0.5 验收项已通过。特别是 Cocos 实际导入、引擎材质和大规模草树性能需要在真实引擎项目验证；Unity/Godot 仅预留适配接口。当前不生成 Windows/Android 安装包。

内置素材统一由 `editor-assets/` 的分类清单管理：城池、五种树木、要塞与草丛均加载 GLB，地表、水面和缩略图直接加载实际 PNG；源码不保存素材字节副本。要塞、草丛由原程序原型转存，运行时不再生成模型。当前四层地表贴图按用户确认采用已有提取资源，仅作为本机研究样板；来源及裁剪、处理参数和哈希记录在 editor-assets/surface/provenance.json，不扩大到公开发布或分发。

## 四层地表研究样板

地表左侧提供真实草地、泥土、岩石、沙地缩略图。右侧“地表材质”可调整纹理尺度（25%～400%）、细节强度（0%～100%），并开关坡度显岩；参数可撤销并随工程保存。材质使用世界坐标三向投射，默认重复尺寸 16／16／32／24 米，修改地图宽长不会拉伸纹理。Cocos 导出暂沿用原基础色，未同步本轮画质。

启动先读取工程自带的独立 PNG，保存的 v3 工程内嵌八张贴图，不依赖原 sanguo 目录。资源重建可运行 `npm run prepare:surface`（需要 Python、Pillow、NumPy 和只读的原始研究图集），脚本只向本工程生成派生文件。地表实际交互验收使用 `npm run test:surface`；固定场景截图使用 `node tests/surface-fixture.cjs`。测试需先启动开发服务。

## 浏览器水面研究样板

水面使用已有河流打包图 R 通道派生的法线与碎纹遮罩，采用 24／8／3 米分层波纹、沿河视觉流动、最终地形水深渐变及变化天空反光。正常及全图镜头保留主波纹，默认视觉流速 0.8 米／秒；这不代表真实水文模拟。它是编辑器显示能力，所有河流共用，不新增地图参数或改变 v3 工程格式；Cocos 仍为基础 PBR 水面。资源仅作本机研究，原图集不参与运行。

重建水纹使用 `npm run prepare:water`，输出及来源记录在 `editor-assets/water/`；验证使用 `npm run test:water`，固定镜头截图使用 `node tests/water-fixture.cjs`。运行浏览器验证前先启动开发服务，截图与实际验收入口见[项目资料索引](.agent/docs/README.md)。

水体区域的可见变化验证使用 `npm run test:water-visibility`；约八秒真实录屏使用 `npm run record:water`，通过浏览器内置录制与解码，不额外安装视频工具。录屏覆盖正常和默认全图镜头，并检查编码后仍能看到水体变化；运行条件和帧率如实记录。
