# Windows 流畅档简化地表与验收

日期：2026-11-01。关联：[性能分步计划](windows-performance-plan.md)第 3 步 · [显示档位](windows-display-quality.md) · [实施记录](implementation.md)。

本轮属于所有地图共用的编辑器开发，仅替换流畅档地表显示路径，不制作地图，不修改地形几何、地图参数、素材、历史、工程格式或 Cocos 导出，不实施按需绘制及后续长任务治理。

## 显示行为与数据边界

- 流畅档使用 `MeshLambertMaterial` 漫反射、四层 XZ 平面颜色贴图及一张共享宏观纹理。四层权重仍从原高度采样对应纹素中心读取并归一化，米制平铺尺度、全局纹理尺度、颜色色调及坡度显岩开关继续生效。
- 坡面岩石使用几何法线坡度和宏观纹理微扰，只在显示时混入岩石层，不写入手绘权重。陡坡仍是同一连续地形，平面纹理允许拉伸；高画质保留三平面呈现，操作指南说明该取舍。
- 简化片元只有权重、四层颜色和宏观纹理采样，不执行程序噪声、三平面或法线贴图采样。流畅视口只解码颜色；原始法线资源继续保留供均衡／高画质、工程保存、备份和导出使用。只替换未使用的法线不触发流畅颜色重载。
- 宏观纹理由固定种子 CPU 周期值噪声生成，128×128 RGBA，两通道分别表达较宽及较细的色差；每 512 米重复，使用线性过滤和 mipmap。它是运行期可重建派生资源，不作为用户素材写入工程，也不是正式地图作品。
- 多个流畅材质按引用共享宏观纹理，最后引用释放时回收；颜色、权重、旧位图和异步过期结果沿用明确释放路径。地表绘制、材质预览／取消、替换、撤销重做及工程切换继续通过原会话和版本机制处理。
- 均衡与高画质仍调用原 `surface-shader.ts` 和 Standard 材质，原程序标识及设置保留。开发分页缓存不接入简化路径。第 2 步的分辨率、阴影和抗锯齿约定不变。

## 功能与画面对照

`npm run test:simple-surface` 启动独立 Vite／WebGL 验证；夹具由测试代码生成四层地表、山脊及陡坡，另用测试生成的纯色 PNG 区分采样通道，不代表正式地图或新增素材。验证四层独立颜色和混合边界、坡度显岩及权重不变、颜色替换／撤销／重做、v4 备份往返、旧颜色纹理和 ImageBitmap 回收，以及共享宏观纹理最终释放。测试保留编辑器 ACES 色调映射，按颜色贡献检查像素，而不要求源纯色在色调映射后其他通道严格为零。

WebGL 报告：[像素与资源验证](../../test-results/tests/simple-surface-render-1793509787660/report.json)。四组验证通过，无页面或着色器错误；释放后 Geometry 计数为零，宏观纹理释放一次。已查看[真实素材与山脊截图](../../test-results/tests/simple-surface-render-1793509787660/fast-builtins-ridge.png)，四层混合、岩石坡面和河岸可读，陡坡拉伸属于流畅档已接受的取舍。

原 dist 125% 缩放切档回归：[真实发布界面验证](../../test-results/tests/display-quality-1793510033873/report.json)。透视／正交、相机、选择、未保存数据、撤销／重做与逐文件内容哈希保持一致；旧上下文释放、单画布／单 RAF、大窗口预算及重启偏好通过。

固定画面使用第 2 步备份版与最终发布版，显式 GTX 1050、相同地图文件内容、相机、125% 缩放及绘制尺寸；冻结渲染端时钟使水面和草停在初始时间，不用于帧率测量。完整示例的均衡／高画质分别跨构建、跨 WebGL 上下文比较，报告：[原画质对照](../../test-results/tests/simple-surface-quality-1793510265353/report.json)。均衡最大通道差异 0；高画质 376 个像素有差异，最大单通道为 1／255，未观察到可见变化；不表述为高画质逐像素完全一致。

相关单元回归 54／54 通过，覆盖简化材质、宏观纹理共享／释放、偏好、地表数据与历史、保存／备份及引擎导出；另有地形更新专项通过。类型、源码引用和改动文件格式检查通过。没有重跑全量单测；既有素材 LOD 阈值问题维持此前记录，不将相关回归等同于全量通过。

## 性能对照方法

工具默认仍以高画质复现第 1 步。第 3 步以相同流畅设置分别测试现路径及诊断用第 2 步地表：

```sh
npm run test:windows-performance -- --baseline-only --quality=fast
npm run test:windows-performance -- --baseline-only --quality=fast --previous-surface
```

`--previous-surface` 必须配合 `--baseline-only`，只在显式诊断启动中选择旧 Standard 地表，保留流畅档分辨率、关闭的 MSAA／阴影、过滤和法线强度设置；不修改产品偏好或地图，不新增 UI 选项。测量记录实际材质类型及程序标识，不能将诊断旧地表结果当成产品默认路径。

两次运行串行、各使用独立临时配置及通过首页生成的相同空白／完整示例输入；相机、窗口、GPU 和绘制尺寸固定，每项预热 5 秒、采样 15 秒、重复三轮，静止及固定平移分别报告。采样排除其他测试，保留 GPU／CPU 时间、FPS、P95 和有效状态，计时限制沿用[第 1 步说明](windows-performance-baseline.md)。

## 默认核显正式结果

本机 i7-7700HQ、HD 630 驱动 31.0.101.2114／ANGLE D3D11、Windows 10、125% 缩放、交流电；未强制独显。内容窗口 1600×1000，实际 CSS 视口 1038×873，绘制缓冲 778×654；两组均为流畅设置、513²、2048×2048 米。对照使用同一 `app.asar`（SHA-256 `e86d9ab864587cff8f430fa7db519a04f18950f9120843655b1c6f432f4424e2`），保存数据逐文件核对：空白 6 个文件、完整示例 7 个文件完全一致；独立工程的入口 UUID 不参与内容相等判断。

报告分别为[当前简化地表](../../test-results/tests/windows-performance-2026-11-01T05-19-09-260Z/report.json)和[同构建旧地表](../../test-results/tests/windows-performance-2026-11-01T05-23-59-324Z/report.json)，各 12 段有效采样，无采样错误。三轮中位数如下，GPU 单位 ms。

| 场景 | 旧地表 FPS | 简化地表 FPS | 旧 GPU | 简化 GPU | 简化 P95 帧间隔 ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| 空白静止 | 31.99 | 60.05 | 28.69 | 9.13 | 16.80 |
| 空白相机运动 | 31.80 | 60.05 | 28.93 | 8.59 | 16.80 |
| 完整示例静止 | 26.33 | 49.38 | 35.29 | 17.76 | 23.80 |
| 完整示例相机运动 | 25.99 | 49.12 | 35.38 | 17.61 | 50.30 |

空白提交均为 1 Draw／524,288 面，完整示例均为 51 Draw／772,141 面，未删对象、降低采样或缩小绘制缓冲。空白静止 CPU 帧墙钟两组约 0.30 ms，完整示例约 1.10 ms；主要收益在地表 GPU 路径。空白 GPU 中位时间减少约 68%，完整示例约 50%，不以此作为全部编辑操作的加速倍数。

本机这组 513² 固定场景达到空场景 60 FPS、完整示例至少 30 FPS 的 FPS 目标。完整示例运动仍有 P95 50.30 ms 的波动，连续笔刷长任务、1025² 性能及不同设备尚未在本步全面验收，继续按后续步骤处理；不将固定场景达标表述为全部地图、所有操作或最终集成验收已经完成。
