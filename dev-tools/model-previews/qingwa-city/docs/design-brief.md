# 青瓦城池 · 设计简报

## 一句话概念

一座用于三国山水战略地图的紧凑型中式城池：防御体量稳重，青瓦与木构层次清晰，在战略地图的斜俯视距离也能辨认城门、角楼和主殿。

## 交付清单

- [ ] 在 `editor-assets/models/` 新增一个自包含 GLB 城池模型。
- [ ] 不修改现有地图、程序模型、应用代码或工程格式。
- [ ] 模型采用米制，约 52 × 46 米占地，地面中心为原点，前端朝 Three.js +Z。
- [ ] 保留可重建的 Blender 源工程与生成脚本。
- [ ] 使用自制几何和自制贴图，不提取参考游戏资源。
- [ ] 提供独立 Edit3D 预览、材质编辑与静态 GLB 验证。
- [ ] 检查主视角、正面、背面和屋顶近景，至少完成一轮发现—修正—复验。

## 参考特征 → 制作决策

本轮以用户提供的《三国志14 威力加强版》城池截图为主要视觉目标，仅观察形制、比例和色彩，不提取游戏资源。

| 参考特征 | 本模型中的落地方式 |
| --- | --- |
| 城墙是连续、厚重的暖浅灰砖石体量 | 保留闭合城墙和真实拱券，砖墙与石基由冷灰绿改为暖浅灰，降低砖缝的脏黑感 |
| 门楼和角楼屋顶低矮、轮廓克制 | 门楼由双重檐改为单层宽屋顶；降低角楼墙身和屋顶高度，减弱屋脊与檐角起翘 |
| 屋顶为低饱和深灰而非鲜明青绿色 | 瓦面与瓦脊改为中性深灰，保留瓦垄和屋面曲面但降低青色与亮线对比 |
| 中央大建筑是唯一视觉中心 | 删除四座厢房，主殿移至城池中部并放大到约 17.2 × 10.8 米，保留完整空旷院落 |
| 正门与四角塔楼构成外轮廓 | 保留四座角楼、宽门楼、拱形双扇木门和城垛，不让门楼高度压过整体城墙 |
| 城池需要在地图斜俯视中可读 | 维持约 52 × 46 米占地，以主殿、院落和门楼三个层级组织轮廓，控制细碎装饰 |

参考核验：用户提供的游戏截图；此前参考中国大百科全书“瓮城”、中新网“平遥古城”、商洛学院“中国古建筑屋顶图解”。不使用任何参考图片作为贴图或模型。

## 尺度与布局

- 总占地目标：X 约 52 米，Three.js Z 约 46 米；Blender 使用 X/Y 地面、Z 向上。
- 主墙高 6.2 米，厚约 1.6 米；石基高 0.7 米。
- 前门位于 Blender -Y，对应导出后的 Three.js +Z。
- 主门洞净宽约 5.6 米，拱顶约 5.4 米；双扇暗红木门。
- 四角塔楼高于城墙；单层门楼降低高度，不再作为最高尖顶。
- 城内只保留一座中央主殿，主殿墙身约 17.2 × 10.8 米、高 4 米；不再生成任何厢房或小建筑。
- 总高度控制在约 15 米以内，屋顶和屋脊的起翘幅度较上一版收敛。
- 原点位于占地中心、地表接触面；导出后不包含预览地形、相机或灯光。

## 光线与环境

- 模型本身不烘焙光照，不包含灯光。
- 预览使用秋季山地、物理天空和 17.5 时低角度日光。
- 城池放在整平建筑基址上，周围有草和少量岩石；环境只用于预览，不进入 GLB。

## 检查视角

1. 前右上方主视角：完整城池、正门和唯一中央主殿。
2. 正面较低视角：拱券、门扇、单层门楼比例。
3. 后左上方：城墙闭合、角楼和空旷院内布局。
4. 屋顶近景：深灰瓦垄、屋檐厚度、木构挑托与材质尺度。
5. 顶视：占地、原点与城内布局。

## 可编辑项

- 根对象：整体移动、旋转、缩放。
- 主要分组：城墙与城门、角楼、城内建筑、装饰与旗帜。
- 材质：青砖、石基、青瓦、木构、门扇、灰浆、金属和旗帜通过材质卡片调整。
- 预览环境：日照时间参数；不属于导出资产。

## 性能预算

- 目标三角形：60,000～160,000；本轮实际 63,628。
- 目标材质：不超过 12 个；本轮实际 11 个，按主要分组与材质合并静态细节。
- 单张贴图 512～1024，GLB 内嵌；目标文件小于 30 MiB。
- 不使用透明大面片、实时水面或额外阴影灯。

## 制作路由

- Blender：城池全部几何、UV、材质、贴图装配、源工程和 GLB 导出。中式曲面屋顶与拱券需要真实拓扑。
- Python：确定性的砖、石、瓦、木纹、灰泥与织物贴图生成。
- Three.js / Edit3D：加载 GLB、提供物理天空、地形、草与岩石、相机环游、对象注册和材质编辑验证。
