# Windows 连续编辑性能优化与验收

日期：2026-11-01。对应[性能计划](windows-performance-plan.md)第 5 步。关联：[实施记录](implementation.md) · [按需绘制](windows-demand-rendering.md) · [资料索引](README.md)。本轮属于所有地图共用的编辑器开发，不制作地图作品；单片连续地形、采样、原始高度、对象数据、工程格式、素材及 Cocos 导出保持原契约。

## 剖析与范围

先用独立 WebGL 夹具采集 513²／1025²、2048×2048 米的空白和固定示例：雕刻远离河流／河流附近、固定相机平移、刷树和据点选择。每段约 2.5 秒，记录输入处理、浏览器 RAF 帧间隔、Long Task 及 CDP CPU profile；1025² 示例由已有夹具重采样构造，不是用户地图或正式作品。

[优化前源码剖析](../../test-results/tests/editing-profile-1793520191904/report.json)和[第一轮优化后剖析](../../test-results/tests/editing-profile-1793520753971/report.json)各 18 项，无页面错误。源码夹具没有整个 React 界面，第一轮未采集 GPU 标识，不能拿它的 RAF 频率冒充真实发布版 FPS。两轮是固定时长输入，处理得快时输入点更多，不能把最终地图当作相同输入的画面对照；算法一致性由独立固定输入测试验证。

确认的热点：

- 最终高度每个插值笔刷点都会复制整图并重算河床。示例 513² 的单点派生中位约 22 ms，1025² 约 85 ms；1025² 雕刻事件 P95 约 97 ms。既有显示网格局部更新通常不到 1 ms，不是此次主要瓶颈。
- 相机移动的近景草生成在主线程执行，513²／1025² 的同步段中位约 36／41 ms。草批次和逻辑范围反复释放材质，CPU profile 同时出现反复 `getProgramInfoLog`／`getShaderInfoLog` 等编译等待。
- 1025² 笔刷结束时历史扫描约 33～56 ms，包含未改变的大数组。真实 dist 的据点名称修改还确认完整校验每像素创建 `subarray`，以及提交后重复扫描高度／权重／密度的成本。
- 水深更新约 3～5 ms、树木笔刷通常约 1～4 ms、一般实例同步阶段约 5～10 ms；本轮未强制把这些路径全部改成 Worker 或重写模型批次。

## 已实施

### 局部最终高度

`deriveHeights` 保留完整派生入口，另允许在独立最终高度缓冲上更新世界矩形。每个雕刻点只恢复该范围内的基础高度，过滤不相交的河流印章，再按原河流顺序、相同距离／混合公式重算局部河床。河流／尺寸、一般命令、撤销、取消和工程替换继续完整派生。原始高度不被河床覆盖；显示端继续复用原 `TerrainGeometry` 脏区与相邻法线更新，没有改为分块。

### 历史与校验

笔刷开始时记录可信的数组修改范围类别，历史只扫描该笔刷可能修改的数组；所有元数据仍比较、保存与恢复。一般命令仍默认全量比较；四通道权重按 32 位字筛选，再逐字节保存原补丁，补丁顺序及非对齐缓冲回退均有测试。历史提交向应用层提供已计算的数组差异，应用层不再重复扫描。校验仍检查所有高度和四层权重，改用直接求和避免每个像素创建临时视图，没有跳过校验。

### 草丛工作线程

工作线程复用核心 `generateGrass`、相同世界种子、稳定身份排序、过滤规则和 50,000 预算。只复制独立高度／密度快照及所需元数据，不传模型字节，不转移文档原数组。最多一个任务执行、一个最新候选；被替代候选立即取消，执行中的旧结果丢弃。结果核对任务 ID、工程版本、地形版本和草版本，视口再检查工程对象／显示代次；取消、快速切图、失败和释放均有清理路径。切档／关闭终止所属线程，不让旧线程回调重启新任务。

### 材质持有

视口持有草动画材质及逻辑填充／格线／边界材质。几何和实例变化时复用材质，避免最后引用释放造成下一帧重编译；不改变着色器、颜色、混合、排序或地图参数。草材质按实际保留批次清理，最终各资源恰好释放一次。

## 一致性验证

[源码集成报告](../../test-results/tests/editing-consistency-1793521379172/report.json)通过 513²／1025²：真实 Worker 输出与同步算法逐对象一致；连续雕刻的最终高度与完整派生一致；撤销／重做、取消、备份恢复保留高度／权重／草密度；延迟旧草结果在新工程加载后不提交；草材质跨重建复用、材质最终恰好释放一次、几何回收为 0。

单测另外覆盖四种雕刻模式、重叠河床、矩形地图边缘、独立缓冲、定向／完整历史相同、原数组未分离、队列合并、错误版本、线程失败重建、取消／关闭及旧线程回调。73／73 相关单测通过；另有源码集成与原生发布版回归。此前全量单测的素材 LOD 阈值问题未改，本轮未将全量单测标为通过。

## 性能及发布版结果

真实发布版对照使用本机 i7-7700HQ、HD 630／ANGLE D3D11、Windows 10、125% 缩放、交流电、流畅档 778×654 缓冲。旧版报告分为[513² 空白](../../test-results/tests/windows-editing-baseline-1793522063759/report.json)和[1025² 空白／513² 示例](../../test-results/tests/windows-editing-baseline-1793522171003/report.json)；[最终版报告](../../test-results/tests/windows-editing-final-1793522971803/report.json)覆盖三者，均通过保存重开和撤销重做。各操作一段，含 CDP 剖析开销；不是三轮正式 FPS 基准。采样期间未执行其他性能／WebGL 测试。报告前后状态核对可见、上下文未丢失、工程版本一致，完整示例草和树均已加载。

[正式固定场景复测](../../test-results/tests/windows-performance-2026-11-01T09-01-27-948Z/report.json)使用同一最终构建、默认 HD 630／流畅档，5 秒等待预热、15 秒强制连续采样、三轮，共 12 段有效：空白相机运动 60.07 FPS／P95 16.80 ms，完整示例运动 51.44 FPS／P95 42.40 ms。空白仍为 1 Draw／524,288 面、示例 51 Draw／772,141 面，完整内容与采样未减少。待机不用于计算这组 FPS，静态预热等待仍遵循按需调度。

[三档最终画面对照](../../test-results/tests/simple-surface-quality-1793523552757/report.json)使用 GTX 1050、相同相机／地图／绘制尺寸、固定非零时钟：流畅和均衡最大差异 0，高画质最大 1／255、468 个像素有差异。第一次流畅对照曾出现城池局部 24 像素差异、最大 49／255，见[保留记录](../../test-results/tests/simple-surface-quality-1793523198064/report.json)；增加只读材质／时间轨迹后复测未复现。模型材质 ID 随异步装载变化，局部共面面片排序是可能原因，尚不能宣称跨装载顺序绝对像素确定性。最终结论限于本轮固定画面，不扩大比较阈值。

## 复现

```sh
npm run test:editing-profile
npm run test:editing-consistency
npm run test:windows-editing -- --label=baseline --exe=<对照版路径>
npm run build
npm run test:windows-editing -- --label=candidate
```

发布版工具使用独立配置，通过真实首页创建 513²／1025² 空白及 513² 示例。`--scenes=blank-513,blank-1025,demo-513` 可选择子集。固定流畅档、1600×1000 内容窗口，雕刻／刷树各 60 次真实鼠标移动、间隔 35 ms；相机为右键观察＋W；据点为真实创建／选择和 8 次名称提交。各段记录浏览器 RAF 响应帧间隔、实际画面提交数、Long Task 及 CPU profile，含剖析开销。RAF 间隔不是 GPU 时间或提交 FPS，输入间隔也不能作为渲染吞吐上限。每次编辑检查撤销／重做，最后真实保存并从近期工程重开比较编码哈希。

第 6 步完整集成验收未执行；保留启动／首次着色器编译、不同硬件、全范围大笔刷、多层高密度草及更多模型的验证边界。不能把局部提速、源码夹具或某次无长任务表述为所有地图、所有编辑操作已达标。
