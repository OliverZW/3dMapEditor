# 架构规则

适用：模块划分、数据结构、地形、渲染、编辑历史、持久化与平台边界。具体功能和实现方案通过 [项目资料索引](../docs/README.md) 按任务定位；代码表达见 [代码规范](code-style.md)。

## 模块职责与依赖

- 编辑器能力与地图内容的归属遵循 [边界规则](editor-map-boundary.md)。核心提供通用数据与算法；具体地图的布局和美术调参不成为算法的硬编码条件，示例数据与通用能力分别标注。
- 核心层负责纯数据、坐标、算法、命令、历史与数据校验，不依赖 React、Three.js、DOM、线程或平台文件 API。
- 应用层协调编辑会话、用例、工具生命周期与异步任务；UI 通过应用层操作地图。
- 渲染层消费地图数据，负责场景、拾取、预览和 GPU 资源；不得维护另一份独立的地图真相。
- IO 层负责格式编解码与资源索引，平台层负责文件、输入和恢复存储适配。
- Worker 入口复用核心算法，通过消息传递数据，不让核心依赖线程环境。
- 不以全局状态绕过层间边界，不引入跨层循环依赖。

## 工程目录职责

- `editor-assets/` 是地图内置素材的唯一来源，保存模型及内嵌贴图、地表与水面图片、缩略图、素材默认参数、分类清单及来源记录；由构建配置作为静态资源发布。源码与测试不保存素材字节副本，核心仅消费纯描述，IO 负责读取与校验。正式地图作品与测试产物另行管理。
- `engine-adapters/<引擎>/` 保存目标引擎的适配代码、读取示例与配套说明。与 `src/io` 的资源包生成逻辑分工，不让引擎 API 侵入核心。
- `dev-tools/` 保存开发检查与资源加工工具，由开发命令调用；加工只写本工程，外部来源只读。应用运行不依赖这些工具，也不把它们当成地图内容。

## 地形与坐标

- 地面使用单个连续规则网格 Mesh，以高度场表示起伏；不得改成地形分块、瓦片或流式地形。
- Y 向上，XZ 为地图平面，物理单位为米；图片向右为 +X，向下为 +Z，数组按行存储。
- 世界、采样和六边形坐标明确区分；六边形仅是独立逻辑叠加层，不决定地面网格形状。
- 拾取、贴地与高度查询采用相同的坐标约定和三角面插值，避免可见地面与数据查询不一致。
- 笔刷局部更新高度、相邻法线及包围体，不因优化而改变单片地面约束。

## 数据与派生结果

- 文档数据是唯一事实来源；基础高度、地表权重、植被实例、河流参数和城池分别存储。
- 基础高度是可编辑原始数据；河床、最终高度、水面网格和贴地结果均可重算，不反写破坏原始高度。
- 稳定 ID 独立于渲染对象和实例槽位；增删、重做、重开不改变对象身份。
- 随机生成结果可复现，不能因为渲染重建或重做而重新抽样。
- 地形或水域变化后同步重算受影响对象；临时不可见不等于删除原始记录。

## 命令、预览与异步

- 正式地图变更通过统一命令提交，保存必要的修改前后数据，以支持一致撤销和重做。
- 预览与正式数据分开，确认、取消、异常中断均有明确提交或回滚路径。
- 镜头和临时选择不进入地图内容历史；新编辑清空重做分支，历史淘汰不改变当前地图。
- 派生重建覆盖新旧影响区域，撤销后同步恢复高度、水面、法线与贴地结果。
- 异步结果携带工程及任务版本，丢弃过期结果，禁止覆盖较新的编辑。

## 持久化与平台

- 工作目录与自包含工程包分别表达：工作目录可引用按标识及内容哈希锁定的共享内置素材，工程自有素材使用目录内相对路径；自包含工程包收齐所需原始资源，恢复不依赖原工作目录或本机绝对路径。
- 资源的共享或工程自有归属显式记录，缺失或哈希不符不得静默替换；已有包内资源不能在转换时自动变成共享依赖。
- 正式保存先写入并校验候选数据，再提交入口；失败保留上次成功工程。恢复草稿、可重建缓存、临时会话状态与正式地图数据分别管理。
- 工程格式与算法版本显式记录；输入先校验候选数据，成功后整体切换，失败保留原工程。
- 校验数组长度、有限数值、坐标、资源引用、路径与资源预算；不执行或信任文件中的任意指令。
- 工程包保存可继续编辑的数据；高度图仅表达地形起伏，不能代替对象、材质和水面数据。
- 高度图采用真正的 16 位灰度 PNG，并附带尺寸、高度范围和方向参数；不得通过 8 位画布输出冒充 16 位。
- 平台文件、输入和存储通过接口适配，不侵入核心；下载、恢复草稿和正式备份分别表达。

## 生命周期与验证

- Geometry、Material、Texture、ImageBitmap、ObjectURL、订阅和 Worker 有明确所有者与释放路径；共享资源按引用管理。
- 渲染循环和高频笔刷计算独立于 React 重渲染，避免无关整图重建和每帧大数组复制。
- 验证坐标一致性、命令回滚、派生结果重建、序列化往返与资源释放。
- 性能结论附设备、资源规模、分辨率和画质条件，不以输入上限或静态截图代替实测。
