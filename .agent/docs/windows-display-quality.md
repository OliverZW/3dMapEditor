## 使用与参数

编辑器顶部“设置”统一管理画质预设与阴影、抗锯齿、简化地表、按需渲染。首次默认流畅、按需渲染开启；选择预设重置开关，单独修改显示“已自定义”，保留预设画面分辨率与纹理过滤参数；阴影尺寸可单独修改。简化地表关闭法线细节。仅点击应用提交，取消不生效，恢复默认仅重置表单。

本机 localStorage 使用 `shanhe.render-settings.v2`，缺少新记录时读取旧 `shanhe.display-quality.v1` 并映射为预设，应用后写入新记录；无效或不可读取记录回退流畅并提示。保存失败提示本次渲染已应用但偏好未保存。旧渲染记录缺少 shadowSize／treeShadows 时，按原预设补齐阴影精度、默认保留树木投影，其余自定义开关不变。总阴影关闭时禁用这两项并保留值；树木投影关闭后跳过树木专用阴影实例的创建与提交，树木仍显示、接收阴影并可拾取，城池与要塞投影保留。流畅和均衡预设使用 1024，高画质使用 2048，树木投影预设均开启。设置不写入地图数据、历史或导出。关闭按需渲染后持续绘制，隐藏或最小化窗口仍暂停；切换复用现有视口重建和失败回退流程。

Windows 显卡选项在同一弹窗内，默认独显优先，可选核显或自动；下次启动生效，详见[桌面开发](desktop-development.md)。本页后续性能数据仍按其历史档位和设备条件解读。

| 设置 | 流畅 | 均衡 | 高画质 |
| --- | --- | --- | --- |
| 初始绘制像素比 | `min(DPR, 1) × 0.75` | `min(DPR, 1)` | `min(DPR, 1.75)` |
| 像素预算 | 最大 921,600，超出时等比缩小 | 不另设上限 | 不另设上限 |
| MSAA | 关闭 | 关闭 | 开启 |
| 阴影 | 关闭 | PCF、1024 | PCF、2048 |
| 地表法线细节 | 关闭 | 使用工程参数 | 使用工程参数 |
| 地表／水面各向异性过滤 | 1 | 4 | 4 |
| 地表算法 | 第 3 步简化地表 | 原有地表算法 | 原有地表算法 |

只缩小三维画布的绘制缓冲，不缩放界面 CSS、文字、按钮或拾取坐标。大窗口按像素预算计算统一比例；窗口大小及 DPR 改变时重新计算。高画质沿用原设置；本轮不调整地图采样、素材、模型 LOD 阈值、密度、光照、色调、工程格式或导出参数。

低层 `EditorViewport` 的独立夹具仍缺省高画质，正式 App 则明确传入本机档位。第 1 步性能工具默认选择高画质以保留历史对照语义，可用 `--quality=fast|balanced|high` 指定实际测试档位；显卡参数与显示档位相互独立。

## 切档与资源

切档复用原编辑 session，地图数据、对象身份、选择、撤销重做及未保存标记均保留。相机快照保留透视／正交、位置、四元数、目标、缩放、裁剪参数、方向状态和导航速度；切档后立即恢复，不重新取景。切档发生在拖动操作或异步任务期间时拒绝切换并提示，避免中断当前操作。

旧视口取消 RAF、计时器及订阅，解绑输入、ResizeObserver 和 DPR 监听，释放模型／地形／水面／材质／纹理，再释放渲染器并丢失旧 WebGL 上下文。新视口只有一个 RAF 循环，恢复相机并绑定当前输入阻塞状态。地表材质更新与预览只读取工程参数，流畅档始终将显示法线强度限制为零，不回写文档。水面资源替换后仍保留当前过滤设置。

## 验证方法

```sh
npm run test:display-quality
```

真实原 dist、独立临时用户配置和首页创建的空白／内置示例工程；通过 Electron 启动参数分别模拟 100%、125%、200% 缩放。验证使用独显以缩短交互等待，属于档位功能验证，不是核显帧率验收；未实测物理多显示器间拖动。

- 每种缩放在透视／正交下重复高画质→均衡→流畅→高画质→流畅，核对实际缓冲、MSAA、阴影尺寸、纹理过滤及地表法线强度；旧上下文必须丢失、DOM 只保留一个画布、稳定后只保留一个 RAF。
- 使用正式工程文件编码及逐文件 SHA-256 比较切档前后的内容，同时检查 revision、文档版本、未保存标记、选择及撤销／重做标签。示例通过真实 UI 重命名据点两次再撤销一次，保留未保存内容及重做记录进行切档。
- 空白地图在不同档位检查同一 CSS 中心的世界拾取；流畅档执行真实抬高笔刷及撤销，验证数据改变及恢复。大窗口请求 3840×2160，按实际绘制尺寸检查像素预算。
- 检查 1280×720／1600×1000 工具条布局，生成真实截图；重启同一临时配置后，通过近期工程重开，恢复均衡档。
- 单元测试覆盖多种 DPR／超大窗口的像素预算、首次及异常存储、相机两种投影恢复和快照独立；并回归已有材质、地形更新、导航及水面测试。

档位实现通过不表示核显已达到空场景 60 FPS／完整示例 30 FPS；后续简化地表与最终性能目标仍按分步计划验收。

## 第 2 步实际验证（历史）

原 dist 已重新构建。三种缩放集成报告：[最终发布版档位验证](../../test-results/tests/display-quality-1793508406990/report.json)。30 组投影／档位切换及 3 组大窗口记录通过，无运行错误；三种缩放重启后均恢复均衡档。100%／200% 空白地图的真实流畅档抬高和撤销通过；125% 示例的未保存据点改名、选择及重做记录在切档前后保持一致。已查看 1280×720 的示例截图，文字清晰、画质控件可见、与坐标系不重叠。

请求 3840×2160 后，实测流畅绘制缓冲为 1219×756（100%／125%）和 1218×756（200%），均在 921,600 像素以内，按同一比例缩小。重复同档位的资源数量稳定：空白地形 Geometry 1，流畅 Texture 11、其余 13；示例 Geometry 78，流畅 Texture 40、其余 42。这些是渲染器资源数量，不是显存字节测量；旧上下文释放和单 RAF 检查另行通过。

相关单元回归两组分别 35／35、24／24 通过（有重叠），覆盖档位／偏好／相机、诊断、地形更新、导航资源、地表及水面；类型、源码引用、格式和构建通过。正常启动的原 dist 桌面回归通过，诊断入口仍默认关闭。本轮没有重新执行全量单测；第 1 步记录的既有素材 LOD 阈值失败未修改，不能将本轮相关测试通过表述为全量已通过。

## 第 2 步默认核显流畅档实测（历史）

命令 `npm run test:windows-performance -- --baseline-only --quality=fast`；原 dist、本机默认 HD 630／ANGLE D3D11、125% 缩放、内容窗口 1600×1000、实际 CSS 视口 1038×873、绘制缓冲 778×654。地图规模、相机及固定平移轨迹沿用第 1 步；每项预热 5 秒、采样 15 秒、三轮，共 12 段有效采样，无采样错误。[正式性能报告](../../test-results/tests/windows-performance-2026-11-01T04-50-21-787Z/report.json)包含输入及构建哈希，三轮中位数如下。

| 场景 | 第 1 步历史原画质 FPS | 本轮流畅 FPS | 流畅 GPU ms | 流畅 P95 帧间隔 ms |
| --- | ---: | ---: | ---: | ---: |
| 空白静止 | 10.56 | 31.94 | 28.79 | 35.30 |
| 空白相机运动 | 10.64 | 31.88 | 28.83 | 35.00 |
| 完整示例静止 | 9.03 | 26.15 | 35.48 | 42.20 |
| 完整示例相机运动 | 8.91 | 26.19 | 35.13 | 109.60 |

本表对比第 1 步历史原画质与当前流畅档，画质条件不同，收益属于整个档位组合。平均 FPS 改善约三倍；完整示例运动仍有明显帧间隔波动。默认核显路径尚未达到空场景 60 FPS／完整示例 30 FPS，下一步仍需简化地表，后续另行治理连续编辑长任务。

## 渲染设置界面验证

本轮通过显示偏好、GPU 参数和调度器共 10 项相关单元测试；桌面工程回归包含预设取消、自定义、抗锯齿实际上下文与恢复默认。`npm run test:render-settings` 在独立临时工程验证连续／按需提交、最小化停止、重复切换相机和数据历史保持、重启偏好恢复。已查看 1280×720 CSS 窗口截图，底部操作可见，长内容在弹窗内滚动。

[本次集成产物](../../test-results/tests/render-settings-1793541082274/)保存截图和实际 GPU 信息；选择集成显卡并重启后，本机活动设备为 Intel HD Graphics 630。该结果验证显卡偏好路径，不作为帧率结论。生产前端构建至测试目录通过，未替换已有发布包。

### 光照性能选项验证

本轮显示偏好、模型批次及渲染优化共 18 项相关单元测试通过；类型和未使用检查、生产前端构建通过。桌面[本轮集成产物](../../test-results/tests/render-settings-1793542200368/)验证三档实际阴影尺寸、总阴影禁用时保留选择、取消不提交、真实示例树木投影反复开关而城池投影保留、相机与地图历史一致，以及重启后恢复 512 精度和关闭树木投影。已查看 1280×720 CSS 窗口截图，设置内容可滚动且底部应用按钮固定可见。本轮未作 FPS 收益测量，也未更新便携发布包。
