# Git 提交规则

适用于本工程及子目录中的 Git 操作。

## 最高要求：禁止直接推送远程

- 禁止执行 `git push`，包括普通推送、强制推送、推送标签和删除远程分支；此要求适用于所有远程仓库和分支。
- 不通过其他命令、脚本、工具或服务绕过此限制，把本地提交、文件或引用直接写入远程 Git 仓库。
- 完成本地提交后，告知用户提交标识和工作区状态；由用户自行决定并操作后续远程推送。

## 提交前

- 按用户要求提交；先检查当前分支、暂存区和工作区，确认提交范围，保留不属于本次任务的现有改动。
- 检查暂存差异，避免纳入凭据、私人数据、无关生成物或未经确认可分发的素材；遵守 `.gitignore` 和素材来源记录。
- 按改动范围执行必要检查，记录实际结果；检查失败或未执行时如实说明。

## 提交与收尾

- 提交内容应围绕清晰的工作目的，提交说明简洁描述实际变更；优先使用中文。
- 不擅自修改已有提交、重写历史、重置工作区或丢弃用户改动。
- 提交后检查提交结果和工作区状态；若有未提交内容，说明其原因和范围。
