## Windows 桌面文件操作（第 2 步）

运行 `npm run dev:desktop` 打开桌面开发窗口；原生目录、进程边界和具体故障处理见[桌面开发](desktop-development.md)。现有保存按钮首次指定尚不存在的新工程文件夹，后续直接保存；打开按钮选择 `project.map3dproj`，校验成功才替换当前地图。取消目录选择不清除未保存标记。

关闭窗口时，有未保存修改则显示“保存后继续／放弃并继续／取消”。保存失败、取消选择或保存期间仍产生新编辑时保留窗口；存在未确认预览或异步操作时提示先处理。关闭批准前释放视口 GPU 资源。首页显示创建、打开和近期工程；创建表单包含名称、父目录、尺寸、采样和默认关闭的示例选项。近期工程可移除或重新定位；返回首页经过相同的未保存保护。

## 1. 总体布局

目标最低窗口 1280×720，左右栏内部滚动，关键动作和错误始终可见。

- 顶部：新建、打开工程、保存工程、导入／导出高度图、撤销／重做、资源库、Cocos 导出。
- 左侧：概览、地形、地表、树木、草丛、河流、据点、势力；地形雕刻模式与地表材质选择位于各自左侧编辑面板，其余工具显示资源或对象列表。
- 中央：三维视口；左上角平铺九个图标，右上角提供可点击的三轴方向坐标系；左下角单行显示 FPS／Draw／模型面数，右下角为单行鼠标和快捷键提示。
- 右侧：地形显示画刷参数，地表另有材质参数；其他工具顶部固定编辑操作，下方滚动显示工具参数或对象属性，切换工具／对象后参数区回到顶部。
- 底部：世界坐标、有效 `{q,r}`、高度采样数、当前操作提示、数量与草稿状态。

左上角依次为投影、六边形格线、树木、草丛、河流水面、城池与要塞、选中据点范围、势力范围、操作提示。图标直接切换并表达状态，悬停说明含操作及可用快捷键；不显示静态视图标签、图层下拉菜单或右上角定位／全图按钮；视口内不叠加工程名称及“单片地形”等说明。显示开关不修改正式数据或导出选项；操作不穿透地图。

### 视觉与状态

延续深色蓝灰、蓝色选中和明确危险色，集中共享颜色／间距／圆角／控件高度变量；常规按钮为 32 CSS 像素，间距以 4／8 为基准。参考 3DNIX 的柔和蓝色光感与 Lumix 的紧凑面板排版，统一操作卡片、列表、数值读数和弹窗状态；选中光感仅作用于 UI，不修改地图材质、光照或后处理。

地图浮层以首版 editor-main.png 为外观基准：工具条使用深灰绿 #152424、约 85% 不透明度，FPS／快捷键使用 #182624、约 70%。普通图标为低饱和浅灰绿 #b5c6bf，文字 #c6d2cb，开启图标保留淡白蓝 #c5e5ff 高亮和同色柔和光晕，选中悬停保持此效果；按钮无蓝色填充，未开启时悬停只略提亮图标，不添加分组竖线。FPS／Draw 位于左下角，实际读数用等宽数字和细分隔线显示，不增加示意帧率或绿色指示灯。右下提示使用同色深色浮层与单行小键帽；键帽采用细边框、微弱底色、2px 圆角和紧凑间距，保留快捷键语义，按当前工具显示具体动作；小窗口保持单行，通过提示内横向滚动查看末尾快捷键。顶部高度收紧，给中央视口留出更多空间。

浮层布局：工具条位于左上，FPS 位于左下，快捷键位于右下，保留当前按钮尺寸，提示按最新要求合并为单行；浮层有轻边框、无容器阴影，快捷键背景仅模糊 3 CSS 像素。透明度只用于背景与外框，不降低文字、图标、快捷键或选中按钮的整体透明度；两侧面板和地图材质、光照、渲染色调保持原样。

## 2. 工程概览与地面大小

左侧首项“概览”集中显示工程名称、实际宽长、采样、树草／据点数量、逻辑网格、资源、河流、势力及格式版本；其他工具不再重复概览。“工程数据”沿用上方参数的卡片样式，每项显示图标、名称和下方数值，面板内滚动查看。右侧宽长以米输入，每边 1～16384 的整数，采样数保持不变，同时显示调整后的间距。

输入尺寸 → 预览调整 → 在地图核对蓝色新边界、红色裁除区域 → 查看树木／据点／归属／草层／河流统计 → 确认调整或取消。确认及取消固定在顶部，参数和统计独立滚动。确认后查看全图；未确认时切换工具或执行冲突文件操作先提示处理预览。

采用中心扩边／裁边，已有内容保持世界坐标；新增地面延续最近边缘，新增草密度为零。缩小会移除越界树木及据点，越界据点的全部辖区释放；跨界河流仅保留内部河段。界面提示逻辑格号可能重新编号，整次调整可撤销。

网格始终覆盖地面，半格裁切；完全在地面外的格子不可编辑。远景降低格线线宽／不透明度以避免遮盖地形，近景恢复清晰度；选中辖区边界独立高亮。大地图全图取景同步调整裁剪距离和雾效范围。

## 3. 镜头与操作优先级

### Unity 风格导航

- 透视：按住右键观察，同时 WASD 前后左右移动、Q 下降／E 上升，Shift 四倍加速；右键期间滚轮调节速度，默认 100 米／秒，每档乘除 1.2，限制 5～1000 米／秒。
- 正交：右键拖动或右键配合 WASD 在视图平面平移；Q／E 不执行升降，也不进入透视飞行。
- 两种投影均支持中键或空格＋左键平移，普通滚轮／Alt＋右键缩放；透视另支持 Alt＋左键环绕目标。
- F 定位当前有效选择，无选择时全图；Home 查看全图。V 切换投影、G 开关格线。镜头与图层不产生地图历史。
- 右下角以单行显示当前工具的左键动作、临时 Shift 操作和有效的 Enter／Esc；右键飞行时改为 WASD、QE、加速及当前速度提示。宽度不足时在提示内横向滚动查看完整内容。

### 方向坐标系

右上角坐标系采用 Unity 风格中央方块、轴杆和锥形箭头，仅显示 X、Y、Z 正方向，颜色分别为红／绿／蓝，标签不带加号。随相机旋转，点击正轴保留投影、目标位置和尺度，以约 0.2 秒过渡到该方向；Y 为俯视。自由导航仍可从任意方向观察，地面背面不可雕刻。

点击中央方块或按 V 只切换投影，Shift＋点击中央方块恢复斜向透视；三个正轴和中心支持 Enter／Space 操作。

左上键盘图标控制右下鼠标／快捷键提示，默认显示，会话内记忆，新建／打开工程不重置。提示不再列出 Home 全图、V 投影、G 格线，但这些按键继续有效；FPS／Draw／模型面数显示独立于该开关。

模型面数每秒更新，使用万／亿紧凑单位，无模型时为 0；统计树木、草丛、城池和要塞在主画面实际提交的三角面，随当前 LOD、实例数量、图层显隐和视锥裁剪变化。不包含地形、水面、辅助图形、放置预览和阴影通道；被遮挡或透明度为零但仍提交的面继续计入，双面透明材质的两次绘制分别计数。它表达绘制负载，不是工程内模型的原始面数总和。

### 输入与工具上下文

- 面板输入、中文输入法组合、可编辑区域及弹窗不触发地图快捷键；Ctrl+F 保留浏览器行为。按钮的 Enter／Space 不穿透地图。弹窗内循环焦点，Esc 关闭并恢复原焦点。
- 手势按下时确定归属，Pointer Capture 跟踪；笔刷期间不切换镜头操作，导航期间不涂刷。松键、松右键、失焦、隐藏窗口或销毁视口后清空移动状态。
- 松开提交笔刷。Pointer Cancel、工具切换或失焦回滚未提交手势；对象／河流预览切换前提示确认或取消。
- Esc 优先关闭弹窗，再退出势力列表／地图添加、取消预览或清除选择；不隐式撤销已提交命令。势力搜索框内也可退出添加，输入法组词期间不拦截 Esc。
- 默认进入据点工具，删除重复的顶层“选择”工具。据点内保留“选择／增加／擦除”模式；绘制不因经过其他模型切换对象，列表切换目标保留模式与逻辑半径。
- 离开据点工具立即清除据点选择及其专属高亮／范围，返回不自动恢复；全局势力范围仍按自己的显示开关工作。势力成员定位、分配不重新选中据点。

### 格线显示

近景普通格线上限约为 1.25 CSS 像素、0.72 不透明度，远景按屏幕密度衰减，选中辖区外边界采用 2 CSS 像素蓝色线；共享边去重，沿地形细分，透视与俯视保持可辨认。逻辑格心吸附仍然有效，不改成自由位置放置。

## 4. 基础美术工具

### 地形与地表

在左侧“地形编辑”的两列操作卡片中选择抬高、降低、平滑或定高；地形、地表卡片上方不再显示重复的“编辑操作”文字。半径、强度、衰减及定高目标高度仍在右侧，参数和范围见需求。地面悬停画圈，快速拖动连续补点；Shift 临时反转抬高／降低，平滑和定高不提示反向升降。说明“编辑基础高度，河流影响区最终由河床合成”。

地表在左侧“地表编辑”的两列材质卡片中选择草地、泥土、岩石、沙地，卡片显示真实纹理缩略图、名称和选中勾号，右侧保留画刷参数，并提供地表材质参数。绘制权重不改变高度；坡度／高度细节开关不清除手绘权重。非法数字就地提示，失焦恢复最近有效值。切换工具后保留各自模式、材质及有效参数。

地表右侧“地表材质”提供纹理尺度（25%～400%，默认 100%）、细节强度（0%～100%，默认 25%）及坡度显岩（默认开启）。尺度越大纹理越宽，不随地面尺寸拉伸；细节强度只控制近景凹凸光照，坡度显岩不覆盖手绘权重。这三项属于工程内容，随保存、重开和草稿恢复，每次连续拖动一次撤销；Esc、指针取消和失焦中断取消未完成预览。

本机研究样板保持草／土／岩／沙四类；未提供更换贴图或新增材质层入口。引擎导出提供参考贴图和权重，游戏侧材质自行实现。

### 树木

左栏显示本工程全部树模型的可搜索虚拟列表，列表项是资源，不是地图中的已放置树。单击即选中笔刷模型，不弹窗、不改实例模型、不重置参数或刷入／擦除模式。各植被工具分别记忆模型与擦除模式。

左栏“导入树木模型”直接导入本类别静态 GLB，成功后清除搜索并定位选中新资源。右侧顶部固定提供“刷入／擦除／选择实例”；选择实例模式下点击实际树模型进行实例编辑，空白处取消选择，不运行笔刷。选实例后选择左栏模型仍只改笔刷资源，实例替换必须用明确动作。

刷入支持密度、缩放、坡度、间距，Shift 临时擦除当前树种。资源为空时提示先导入，不创建笔触；树草显示统计与最终验收边界见实施记录。

### 草丛

左栏为全部草模型虚拟列表，提供“导入草丛模型”和当前模型“详情”；资源与搜索规则同树木。右侧顶部始终提供“刷入／擦除”按钮及半径、密度、缩放、坡度，不提供独立海量草实例列表。

默认半径 20 米、密度 2 丛／平方米、缩放 0.8～1.2、最大坡度 30°；与树木“株／100平方米”区分。默认 60～80 米淡出，最多约五万丛；密度、资源与种子随工程保存，镜头变化不重排原始分布。详细风动／距离参数面板仍属设计目标，交付边界以实施记录为准。

清空当前草层只清所选草模型对应的密度，形成一次历史；不影响地表草纹理、树或其他草层。临时隐藏不删除记录。

### 河流

左侧“河流编辑”在地图河流列表上方提供“新建河流”，预览期间禁用以避免覆盖当前编辑；右侧顶部保留“编辑控制点”及预览期间的确认／取消。左键添点，至少两点；拖动蓝色节点调整位置，Enter 直接确认有效预览，Esc 取消。Delete 删当前选中节点但不能少于两点；删除整条河流使用专用动作。

右侧“河流名称”支持中文与重名，去除首尾空白，空名提示错误。已有河流失焦时提交一次改名；新建及编辑预览中的名称随确认提交、随取消丢弃。输入框与中文输入法组词不触发地图快捷键。

不同河流可交叉、接入或重叠，单条河流仍不能自交。实际水面接触后，预览显示交汇相连的其他河流名称、数量和目标水位；确认时整组采用当前编辑河流的水位，各自宽深、控制点和身份保留。任一受影响河床越出高度范围时禁用确认。整组修改只形成一条历史，取消与失败保留全部原值；水面裁切去重、交汇内部无河岸亮边。

宽深水位默认 24／6／24 米。蓝点可拖、橙色虚线为未提交中心线、半透明带为影响范围；错误段标红并禁用确认。确认形成一条命令，取消恢复原状态，移动或删除重算河床和植被。水面流动只是动画效果。

浏览器水面使用分层水纹法线、深浅渐变、变化反光和外岸碎亮纹；浅岸偏绿、深水偏蓝。正常距离及全图保留主波纹，近景补充微纹；持续观察 1～2 秒可见流动和零散波光。纹理按控制点顺序表达视觉流向，同水位交汇平滑混合，不能据此判断真实上下游。修改河道、深度、水位或雕刻周围地形后显示自动更新，撤销重做同步恢复。这属于编辑器显示能力，所有河流使用相同样式，不新增水色／流速控件。水纹加载失败会提示并保留基础水面，仍可编辑。v2 导出提供水面参考数据，游戏侧效果自行实现。

## 5. 资源详情与全局资源库

树木／草丛左栏当前模型的“详情”打开单个模型对话框，包含三维预览、尺寸、面数、材质数、来源、基础缩放／朝向／贴地偏移、引用数量及删除。这里不显示模型列表、类别导航、搜索或“用于当前工具”。关闭返回原工具、模型与模式。

详情预览与地图相机独立，基础校正同步预览；校正影响全部引用，实例变换仍在实例属性中调整。删除被引用资源必须先处理引用，删除当前无引用资源后选择回退到同类可用资源。

顶部全局“资源库”仍进入四类资源管理视图，与工具内单模型详情共用详情组件。打开时分类、选中卡片与当前资源详情对应；左侧四类筛选，中央资源卡片，右侧资源预览和属性独立滚动，“用于当前工具”等主要操作固定在右侧底部。类别图示不冒充专属模型缩略图；资源预览相机与地图相机独立。

导入：先选类别 → 选 GLB → 校验 → 看模型尺寸与方向 → 设置基础缩放／朝向／贴地偏移 → 确认。失败保留原资源和地图，说明具体资源错误。修改已引用资源的基础校正时提示影响全部引用并显示数量；单个对象的变换在实例属性中编辑。

在全局资源库选资源点击“用于当前工具”后返回地图并进入匹配工具。城池／要塞放置使用各自类别，树／草进入对应笔刷。

从所选对象进入“替换模型”时只显示匹配资源，保留实例变换；树木可明确选择“当前实例”或“全部引用此模型的树”，显示数量后确认。被引用资源“删除”不可直接执行，提示替换或处理引用。来源与许可信息可查看。

## 6. 据点与六边形辖区

### 创建与选择

据点工具左栏提供城池／要塞分类及“新建城池”“新建要塞”。选模型、悬停显示吸附格心的半透明模型、左键点击锁定，再确认放置。点击后移动鼠标不改变候选中心，可再次点击改选；只悬停不能确认。未命中地面的点击清除旧候选，避免误提交前一位置。名称不能为空，其他中心被占用时标红并不能确认。

选择使用实际模型射线命中，不用点击地面到模型中心的距离猜测。城池／要塞统一以 GLB 模型水平包围盒中心作为放置锚点，保留原始 GLB 字节；预览和正式模型使用同一变换。列表或选择模式点击模型可选中；右侧显示类型、名称、模型、中心、朝向、缩放、所属势力和范围统计。两类据点没有父子选择项。水域与陡坡放置只警告，不自动整地。

### 画范围

选中已放置据点 → 选择势力（也可未分配）→ 右侧顶部固定区中的“选择／移动／增加辖区／擦除辖区”操作 → 选择逻辑半径 0～4 → 左键拖动。半径旁显示覆盖格数，右侧强调这是“格圈”，与美术笔刷“米”区分。

范围工具允许临时显示逻辑格线，退出后恢复原开关；若隐藏范围导致难以辨认，提示开启范围显示，不暗中改变业务数据。

所有中心格显示中心标识，画刷跳过；鼠标经过别的辖区时预览“将转移 N 格”，经过别的中心显示“中心受保护”。一次拖动可整体撤销，不逐格弹确认。

“擦除”只清当前据点普通辖区；“清空辖区”确认后清空普通辖区，保留中心。统计显示“中心 1 格／辖区 N 格”，总范围另可显示 N+1。允许空辖区、飞地及跨水域范围，不检查连通。

选中据点范围加强蓝色轮廓，填充优先用所属势力色；势力范围另开关，同势力内部边可隐藏。无势力据点中性色，无归属格透明。

### 移动与删除

选择“移动据点”，悬停预览、点击锁定新的格心；确认前说明“原辖区保留原位置，旧中心释放，新中心转归当前据点”。目标是别的中心时禁用确认；普通辖区可转移，说明原归属。

原地确认无变更；取消恢复原中心和全部归属。删除前说明释放中心与辖区，删除／撤销不改变地形。

## 7. 势力面板

势力工具提供新增、名称、颜色、成员城池／要塞与总格数。成员项明确标记类型，分别提供“定位”“移出势力”，定位保持当前势力面板和正交／透视视角。选势力时显示其派生范围，不能直接刷第二套势力领土；绘制必须选择具体据点。

选中势力后，顶部固定区“添加据点”展开可搜索并筛选城池／要塞的列表，列出当前所属势力；选择即加入当前势力。“地图点选”关闭列表并进入地图添加模式，左键命中模型即可添加。两种添加方式互斥，打开列表会退出地图添加；列表模式点击地图只查看，不加入据点。

“地图点选”选中后保留名称与指针图标，仅以高亮表示当前模式；再次点击当前入口或 Esc 返回查看状态，允许两个入口都关闭；在搜索框输入时也能用 Esc 退出，输入法组词期间不拦截。加入一个据点后保留当前列表／地图方式，方便连续添加。切换势力、离开势力工具、删除当前势力或载入工程均清除添加状态。其他势力的据点会转移归属并显示结果；模式切换不修改地图或产生历史，实际成员转移、移出仍可撤销，逐格据点归属不变。

据点属性中切换势力只改变成员关系与范围颜色。删除势力确认说明“据点及辖区保留，成员改为未分配”，操作可撤销。不提供都城、外交、资源产出或战斗属性。

## 8. 工程、高度图与导出

新建／打开／替换地形遇到未保存内容时可导出后继续、放弃或取消；加载失败保留原工程。Ctrl+S 生成 `.map3d` 下载，提示确认浏览器下载，不称已验证磁盘写入。本地恢复草稿提示位于右下快捷键上方，保留间距，避免遮挡操作提示。

**后续文件夹工程操作（已确定、待实现）**：新建增加名称及本地位置，已有目标目录拒绝覆盖；打开选择 `project.map3dproj`，正式保存写入工程目录，“备份工程”另生成自包含 `.map3d`。旧 `.map3d` 仍可打开，通过“另存为工程文件夹”转换并保留原包。草稿恢复须由用户选择。详细文件与失败保护规则见[地图工程规范](map-project-format.md)；当前按钮与浏览器下载流程尚未切换，桌面界面改造另行设计。

高度图预览位深、方向、单位和重采样，烘焙河床重复导入时提示保留／移除河流或取消。导出为 16 位 PNG＋参数 JSON，不包含模型、辖区、势力或水面；不清除工程未保存标记。

“Cocos 导出”生成协议 v2 数据包：选择内容 → 查看交付说明 → 生成并下载。游戏自行加载、配置、替换模型／贴图／材质，不自动组装场景。地形、高度图与权重必需；其他内容可选，开启但没有内容仍输出合法空数据。视觉开关与逻辑、草排除依赖独立，编辑器显示开关不决定导出内容。

点击生成时隔离快照，实际执行字段、文件、数组及引用检查，失败显示原因且不提供下载。默认正式数据包，编辑器专有材质效果不构成生成门槛；不新增效果模式界面。成功反馈表示 ZIP 已生成，并提示按包内协议和读取示例接入；真实引擎导入与运行保持未验收状态。完整格式见[通用协议](engine-export-spec.md)。旧 v1 场景导入扩展已移除；Unity／Godot 无可用导出入口。

## 9. 快捷键与反馈

顶部“操作指南”按概览与尺寸、镜头与显示、地形与地表、树草与模型、河流、据点与辖区、势力、保存导出和快捷键分节说明当前操作。弹窗保持深色风格，标题与关闭按钮固定，正文独立滚动并可通过键盘聚焦滚动；Esc 关闭后恢复原焦点。指南只描述当前已实现入口，河流 Enter 直接确认有效预览，Delete 用于选中树木或河流预览节点。

- Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Y／Ctrl+Shift+Z 重做。
- F 定位，Home 全图，V 投影，G 格线；Esc 按优先级取消；Delete 在河流节点编辑时删节点，否则删除当前选中的树木。
- Enter 确认有效河流、据点或尺寸调整预览；输入框聚焦时不触发地图操作。
- Shift 在树／草临时擦除，在抬高／降低工具反向；逻辑辖区使用明确的增加／擦除模式，不复用易误触手势。

无历史时禁用撤销，未提交预览阻止冲突操作。坐标越界、中心保护、转移格数、文件错误、配额不足和不支持 WebGL2 均给出可读原因。完整功能验收场景见需求 AC-01～AC-17，当前应用验证与未覆盖项见实施记录。
