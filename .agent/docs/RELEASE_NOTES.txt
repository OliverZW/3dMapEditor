Version 0.2.0 | 2026-11-01
- Windows 多显卡默认优先高性能显卡，显式低功耗启动选项仍有效；实际显卡和性能以本机验收为准。
- Windows 性能更新：默认流畅档，另提供均衡／高画质，本机记忆偏好，切档保留编辑状态。
- 流畅档使用简化四层地表；按需绘制减少待机重复提交，水草动画及窗口恢复继续响应。
- 连续雕刻局部更新最终高度／河床；近景草由工作线程派生，复用材质并减少历史／校验重复工作。
- 原始采样、对象数据、目录工程及导出协议保持不变；本机性能与残余尖峰见项目 Windows 验收报告，不能视为所有设备／地图已达标。
- Windows 桌面工程首页、近期工程、空白及示例工程创建，支持原生保存和未保存保护。
- 新版目录工程与 v4 自包含备份，自定义 GLB 模型及地表贴图导入；不兼容旧版工程包。
- 本机 MSI 测试包包含仅供本机研究的素材，不得公开分发；真实 Cocos 导入运行尚未验收。
